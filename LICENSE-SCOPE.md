# Alexandrian Library licensing

Alexandrian Library uses different licenses for software and public learning
material. A license notice inside a specific file overrides this general map.

## MPL-2.0

The following project-authored material is licensed under the Mozilla Public
License 2.0:

- Python source code and tests
- Schemas and validators
- Agent skills and host configuration templates
- Default project configuration
- Build and package metadata

The complete license text is in [LICENSE](LICENSE).

## CC BY-SA 4.0

The following project-authored material is licensed under the Creative Commons
Attribution-ShareAlike 4.0 International license:

- `README.md` and `LICENSE-SCOPE.md`
- Material under `docs/`
- `next_steps.txt`
- Public primers and example books intentionally placed under `examples/`
- Project-authored cover art under `frontend/assets/`
- Project-authored image-generation prompts under `frontend/assets/`

When sharing or adapting this material, credit the Alexandrian Library
contributors, link to the source when reasonably practical, identify changes,
and preserve the required license terms.

The complete legal text is in
[LICENSES/CC-BY-SA-4.0.txt](LICENSES/CC-BY-SA-4.0.txt).

## Private and generated user material

Content under `data/` is private runtime material and is excluded from both
repository licenses. This includes conversations, source approvals, research
artifacts, generated books, settings, and editorial decisions.

The project does not claim ownership of that material or automatically license
it for public reuse. Its users and other applicable rights holders retain their
rights, subject to applicable law, provider terms, source licenses, and
third-party rights.

A user may intentionally publish selected material under a separate license.
Moving a reviewed work into `examples/` and marking it for public release makes
the repository's CC BY-SA 4.0 rule apply only when the person publishing it has
the rights needed to grant that license.

## Third-party material

Quoted sources, trademarks, model output, external datasets, and other
third-party material retain their existing rights. Citation or inclusion does
not relicense them.

ASD-STE100 specification text, controlled dictionary content, rules, and
examples are not included in or relicensed by this repository. A future
publication profile must use separately obtained authorized material and
respect the standard owner's copyright and trademark terms.

The official license texts in `LICENSE` and `LICENSES/` are provided as their
respective license stewards publish them. They are not project documentation
licensed under the rules above.
